## 报告方法
- 五个主方向：LLM/大模型、AI Agent、自动驾驶、具身智能/世界模型、AI 与数学研究；另设 Other。
- 每个方向报告精选 10 个项目，重点解释背景与痛点、项目采用的方法/架构、具体解决的问题、关键证据与潜在影响，并提供针对项目本身的阅读路线。
- 关键术语链接到根目录 glossary/，跨期复用并持续维护。
- 区分官方事实、公开实验结果、独立验证与分析推断。
- Star 热度仅作为发现线索；没有同口径快照时不声称周增排名。
- Markdown 是唯一交付格式，不自动生成 PDF。
