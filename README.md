## 报告方法

- 五个主方向：LLM/大模型、AI Agent、自动驾驶、具身智能/世界模型、AI 与数学研究；另设 Other。
- 01–06 六份方向报告统一成三个章节：整体结论、本周焦点、Top 10 项目技术分析。
- 每个方向精选 10 个项目，**每个项目独立配一张项目级结构图**，并用约 300 字以上分析瓶颈、架构/数据流、机制、证据、取舍和失效边界。
- 项目分析以技术理解与判断为结论，不添加泛化的“如何阅读项目”或源码学习路线；可将原始源码、测试、论文和 benchmark 链接直接放进分析。
- Mermaid 统一使用纵向布局、相同字体及节点间距配置；关键术语直接链接 Google 搜索解释，并用 Markdown title 提供中文悬停提示。
- 总报告应总结本周有来源支持的具体技术变化，不用常年通用方法论充当本周结论。
- 区分官方事实、项目方声明、独立验证与分析推断。Star 热度没有同口径采样数据时不声称周增排名。
- Markdown 是唯一交付格式，不自动生成 PDF。
