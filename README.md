## 报告方法

- 五个主方向：LLM/大模型、AI Agent、自动驾驶、具身智能/世界模型、AI 与数学研究；另设 Other。
- 每个方向报告精选 10 个项目，**每个项目分别配一张项目级结构图**，并用约 300 字以上拆解背景与瓶颈、架构/数据流、关键机制、证据、取舍和失效边界。
- 源码阅读路线追踪项目真实模块与测试；项目图以官方文档、论文和可见实现为依据，未能确认的部分应明确标出。
- 关键术语使用带 title 释义的 Markdown 链接；根目录 glossary/ 跨期维护定义、机制、假设、代价、相邻概念和常见误用。
- 总报告解释跨方向的架构范式、技术取舍和证据链，而不是复制项目列表。
- 区分官方事实、项目方声明、独立验证与分析推断。
- Star 热度仅作为发现线索；没有同口径快照时不声称周增排名。
- Markdown 是唯一交付格式，不自动生成 PDF。
