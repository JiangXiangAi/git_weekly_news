# Git Weekly News

每周开源科技与数学研究洞察：按技术方向生成子报告，并汇总为综合报告。

## 报告目录

- `2026/2026-10-05_2026-10-11/`：2026 年第 41 周（10 月 5 日至 11 日）

每周目录包含五份方向子报告、综合报告、来源与口径说明。Markdown 为源文件；PDF 由 GitHub Actions 自动构建并归档。

## 方法原则

- 关注 LLM、大模型、AI Agent、自动驾驶、具身智能/世界模型、AI 与数学研究。
- 将榜单热度、项目成熟度、技术意义与研究价值综合考虑；Star 不作为唯一排名依据。
- 事实、推断和预测分开陈述；没有历史快照时不声称跨期增长。
- 每份报告标注统计周期、采集日期与来源；数据不可核实的字段明确标注。
