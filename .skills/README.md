# Repository Skills

本目录沉淀周报生成、技术判断和 Markdown 交付的可复用规则。每周任务开始前必须先读取对应 Skill；发现新问题时，先修正文档，再按该规则修改报告。通用流程只维护一份规范，避免规则散落在每周报告中。

## Skills

- [GitHub Trending 技术周报](github-trending-weekly-report/SKILL.md)：固定报告结构、本周焦点选择、项目精读、项目级架构图、术语外链、粗体/Markdown 检查与证据分级。
- [调整记录](github-trending-weekly-report/CHANGELOG.md)：记录规则变更、变更原因及验证方法。

## 维护原则

1. Skill 是长期规则，单周事件和项目发现仍写入当期报告。
2. 新要求先记录“问题—规则—验证方法”，不只记录一句结论。
3. 规则冲突时优先遵守用户最近明确提出的要求，并同步更新 Skill 与每周自动化任务。
4. 写入 GitHub 前检查实际 Markdown 源文本；不能只凭工具返回成功就认为网页渲染正确。
