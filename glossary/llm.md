# LLM 与推理系统词典

- **Transformer**：以注意力机制和前馈网络为核心的序列建模架构。它能根据上下文聚合信息，但不保证事实核验或长程规划。
- **KV Cache**：自回归生成时缓存历史 token 的 key/value 张量，避免重复计算。它降低重复计算，但会随上下文长度、层数和并发量消耗显存。
- **PagedAttention**：以分页式方式管理 KV Cache，减少内存分配浪费。它主要改善内存管理，不自动提升模型质量。
- **Continuous Batching**：请求完成或新请求到达时动态调整批次，提高设备利用率；吞吐收益可能伴随单请求延迟变化。
- **量化**：用较低精度表示权重或激活，降低存储和计算成本。收益取决于格式、校准、硬件内核和任务。
- **低比特推理**：以低位宽执行模型计算。需要区分权重量化、激活量化、累加精度和内核支持，不能只凭位数推断速度。
- **模型网关**：在业务和多个模型提供方之间统一路由、限流、重试、成本统计和日志；统一接口不代表模型能力相同。
- **TTFT（首 token 延迟）**：从请求发出到首个输出 token 到达的时间，与每 token 延迟和总吞吐不同。
- **结构化生成**：通过 schema 或语法约束输出格式。格式合法不代表语义正确或事实真实。
- **GGUF**：常用于 llama.cpp 生态的模型文件格式。格式兼容只是运行前提之一，仍需核对模型架构、量化和后端。
