# 技术术语词典

本目录是跨期复用的知识层，不属于任何单周报告。报告第一次出现关键术语时链接到这里；后续周报沿用既有词条，只有定义、边界或技术路线变化时才更新。

## 分类
- [LLM 与推理系统](llm.md)：Transformer、KV Cache、量化、推理服务等。
- [Agent 与软件工程](agent.md)：工具调用、状态图、记忆、评测与权限等。
- [自动驾驶与机器人](robotics.md)：闭环仿真、VLA、模仿学习、sim-to-real 等。
- [AI 数学与形式化验证](math.md)：Lean、形式化证明、神经符号推理、证明检查等。
- [研究证据与评测方法](evaluation.md)：基准污染、复现、证据等级、Star 趋势口径等。

## 维护规则
1. 解释是什么、解决什么问题、与相近概念有什么区别。
2. 容易混淆的概念明确边界与反例。
3. 词典记录相对稳定的概念，项目版本细节链接到官方文档。
4. 报告中的推断不写成词典事实。
